The interactive multi-mission sky atlas (Aladin Lite, CDS) loads on demand to keep memory low.

Dashed box = the SPHEREx field shown in the viewer. Catalogue overlays (Gaia, AllWISE, CatWISE) can also be drawn directly on the SPHEREx frames from the toggles under the viewer.

  1. Resolve. Names go through CDS Sesame (SIMBAD) with mirror fallbacks; the five challenge targets are built in. Positions are propagated with their proper motion to the SPHEREx epoch: WISE 0855 is ~3.5′ from its J2000 position.
  2. Search. IRSA's SIA service lists every SPHEREx DR1/QR spectral image covering the target.
  3. Read only what's needed. Each 65 MB image file is read with HTTP range requests: the header, the wavelength table and just the pixel columns of the rows we need (multipart ranges), typically ~50 KB per exposure instead of 4 MB via the cutout service.
  4. Reproject. Pixels are resampled onto a common north-up grid with the full SIP-distortion WCS; the zodiacal/sky background is removed with a clipped median.
  5. Stack. Exposures are grouped into epochs. Each detector is stacked with inverse-variance weights and per-pixel outlier rejection (cosmic rays), then detectors are combined with equal weight, so brightness is comparable between epochs.
  6. Blink & subtract. The browser does all display maths (stretch, colour, difference imaging), so every slider reacts instantly with no server round trip.
  7. Spectrum. Clicking a pixel runs aperture photometry on every exposure; SPHEREx's linear-variable filters give each one a different wavelength, which builds a 0.75–5 µm spectrum binned into 102 channels.

Data: NASA SPHEREx via NASA/IPAC Infrared Science Archive (IRSA). Context: ESA Gaia DR3, NASA WISE/NEOWISE (AllWISE, CatWISE2020) via CDS VizieR; Aladin Lite © CDS Strasbourg.

How to hunt for moving objects

  1. Pick a target (or type coordinates) and press Explore.
  2. Press Space to blink the epochs. Fast movers shift between frames; variables change brightness.
  3. Use −Static difference mode: fixed stars cancel out, and movers appear as black/white pairs.
  4. Turn on Gaia / CatWISE overlays to check whether a mover is already catalogued.
  5. Click a source to plot its infrared spectrum. Brown dwarfs are bright near 4.5 µm and faint below 3.5 µm.
